目标：在 Side Panel 里直接用 ChatGPT 网页当 Provider，调用本地 WebMCP。ChatGPT 这部分完全照搬已经做好的 ChatGPT Embedded Panel，DeepSeek 保持不变。每一步都按本页对照、验收、审查，状态也记在本页。

原则（每一步都必须遵守）

  1. 照搬，不重新设计。ChatGPT 的界面和嵌入机制复制自 ChatGPT Embedded Panel，工具循环复制自 DeepSeek。凡是与原文件不同的地方，都要在“差异清单”里逐条写明理由。
  2. 一步只做一件事。只改这一步范围内的代码，不顺手整理其他东西。
  3. 以你在真实 Chrome 里的验收为准。自动测试只是辅助证据，不能代替你的实测。
  4. 每一步都要审查，里程碑还要做独立审查。完成一步后，先把改动和本页清单对照一遍；到里程碑时，再请 Codex 独立审查。
  5. 权限设置留在 WebMCP App。目录和 High Trust 都在屏幕顶部的菜单栏 App 里设置；Side Panel 只负责选 Provider 和聊天。
  6. 最终形态：一个 Unified Work Side Panel 加一个 WebMCP App。POC 可以分阶段做，但每一处改动都要朝这个形态走，不再产生新的临时 UI 架构。

每一步的固定流程

1 写清本步范围→ 2 只改本步代码→ 3 自动测试 + 照搬一致性检查→ 4 你在真实 Chrome 验收→ 5 对照清单审查→ 6 本地提交这一步→ 7 更新本页状态

“照搬一致性检查”：用脚本把 sidepanel-chatgpt.*、frame-policy.js、embedded-chatgpt.js 和原面板的对应文件逐行比对。除了差异清单里登记过的修改，出现任何其他不同都算失败。上次页面加载错脚本的 bug，就是这一步能拦下来的问题。
